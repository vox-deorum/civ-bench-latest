Controlled CivBench on Vox Populi 5.2.7, Civilization V

PerformanceA controlled version of CivBench (Chen et al., 2026). Each LLM strategists rotate through 3 standard maps (8 players), each game features 2 of the same LLM strategists + 6 Vox Populi AI players. Experimented with 2 conditions: having LLMs make a decision every turn (base); having them make a decision every 5 turns, or when an important event comes up (per-5).

Compare strategists' strength, progress, cost, and token use, with coverage checks to show which experiments support the results.

Usage, cost, and skillCompares cost and token use per player per game with skill, and measures Elo above or below the fitted usage-skill curve.

Most cost-efficient: GLM-5.3-Simple-Per-5 (+95 Elo vs the fitted curve). Least cost-efficient: Qwen-3.6-27B-Simple-Per-5 (-120 Elo vs the fitted curve).

Relative

Strategists

Adjusted strength over the game, the scale the ratings use. Each point is the rating a run would get if the game ended there: its victory probability averaged up to that point the way the rating averages it, compared with the mean VPAI self-play value on the same map and seat, so 0.5 means level with VPAI from the same start. A strategist can sit above 0.5 here with a low absolute probability when it drew hard seats. Only controlled games count, and winner enforcement is off so the final outcome does not lift a whole curve. Checkbox choices apply to both views.

Absolute

Strategists

Each curve is the mean of every run's interpolated victory probability on the fixed 0 to 1 progress grid, pooled over all games. Probabilities are averaged linearly to compare with their expectations (12.5% in 8-player games, for example). The VPAI reference curve is drawn thicker when present. The vertical axis fits the visible curves. Only VPAI and the best and worst strategists by mean curve value start checked; All and Best and worst switch the selection. Hover a checkbox to preview or highlight that strategist's curves, or a legend entry to highlight its curve. Hover the chart to compare every visible curve at one progress point.
