Controlled CivBench on Vox Populi 5.2.7, Civilization V

RatingsA controlled version of CivBench (Chen et al., 2026). Each LLM strategists rotate through 3 standard maps (8 players), each game features 2 of the same LLM strategists + 6 Vox Populi AI players. Experimented with 2 conditions: having LLMs make a decision every turn (base); having them make a decision every 5 turns, or when an important event comes up (per-5).

Compare strategists' relative skill across games, using ratings that summarize how consistently they outperform their opponents.

Pairwise skill ratingsEstimates each player type's relative skill from pairwise comparisons of model-adjusted strength within each game (Bradley-Terry Elo ratings).

GLM-5.3-Simple-Per-5 leads 39 identities at 1633 Elo; rating spread: 322 points.
